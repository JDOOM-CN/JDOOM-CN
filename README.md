# JDOOM

Unlock ports. Let the browser speak non-Web protocols.

If it's a web page, render it. If it's a service, identify it.
Replace a dozen protocol clients and dark terminals — one browser handles every port.

## Overview
JDOOM is a browser-native networking tool built to access, inspect and interact with non-web network services directly inside your browser.

You no longer need multiple terminal clients or heavy dedicated software. Your browser acts as a universal port client to communicate with raw network services.

## Features
- Establish raw TCP connections within the browser sandbox
- Render plaintext service output and inspect network responses
- Capture service banners and recognize basic protocol fingerprints
- Cross-platform: runs on any modern web browser
- Lightweight, zero local installation required

## How it works
JDOOM leverages browser networking capabilities to talk directly to TCP services.
It sends raw data and displays responses, making it easy to test, diagnose and explore network ports without external tools.
